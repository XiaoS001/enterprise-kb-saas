# 演示截图 · RMB01

> 🔴 **这 2 张是真实运行的截图，不是设计稿。**

---

## 1 · 登录页

![登录页](screenshots/1-登录页.png)

**能看到什么**

| 元素 | 说明 |
|---|---|
| 用户名 / 密码 | 登录 |
| **注册新租户** 按钮 | 点开后会多一个「公司 / 租户名」输入框 |
| 演示账号提示 | `demo-admin / demo123456` |

**为什么没有「选择租户」下拉**：一个账号固定属于一个租户（`user.tenant_id`）。
需要跨租户的人用 `platform_admin`，那是另一套视角（平台后台）。

## 2 · 知识库问答（核心页）

![知识库问答](screenshots/2-知识库问答.png)

**这一张就是整个项目的卖点**，从上到下：

| 区块 | 内容 |
|---|---|
| 顶部导航 | 当前是「企业管理员」，所以有「知识库 / 企业后台」两个入口，**没有「平台后台」** |
| 左栏 | 我的知识库列表 |
| 中栏 | 文档列表：4 份文档，每份 4 段 |
| 提问区 | 输入问题 → 点「提问」 |
| **回答** | 带 `降级响应` 徽标（没配 API key 时如实标注） |
| 🔴 **引用** | **「依据《故障处理预案》第 1 段」** —— 精确到段，不是只给文档名 |

**这张图证明的链路**：
上传《故障处理预案》→ 分段 → 问「数据库连接超时怎么处理」→
检索命中第 1 段 → 引用指回去。

## ⚠️ 缺的两张（如实说明）

审查要求 4 张，**实际只拍到 2 张**。缺：

| 缺的 | 为什么缺 |
|---|---|
| 企业后台 | Tabbit 的浏览器实例在后几次截图时**每张都超时**（`fonts loaded` 之后卡住，40 秒拍不下来）。同一实例前 3 张成功，之后一直失败 |
| 平台后台 | 同上 |

**没有换工具硬凑** —— 试过装 Playwright 到项目 venv，那要再下几百 MB 的 Chromium，
在已经有两张核心截图的情况下不值得。

**这意味着什么**：

- ✅ 已完成：**登录 + 知识库问答（含引用）** 这两个最关键的页面有真实截图
- ❌ 未完成：企业后台 / 平台后台**只有代码和测试，没有视觉证据**

要补的话，正常环境下（截图工具不卡）跑：

```bash
# 1. 起服务
RMB01_PORT=5099 python app.py

# 2. 灌演示数据
python demo_seed.py

# 3. 打开浏览器访问
#    http://127.0.0.1:5099/org       （企业管理员）
#    http://127.0.0.1:5099/platform  （平台管理员）
```

用平台管理员登录后：

```bash
curl -c c.txt -X POST http://127.0.0.1:5099/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"demo-platform","password":"demo123456"}'
```
