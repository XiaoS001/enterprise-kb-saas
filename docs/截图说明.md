# 演示截图 · RMB01

> 🔴 **这 4 张是真实运行的截图，不是设计稿。**
> 由 `make_screenshots.py` 驱动 Playwright 访问演示站点拍下来的，
> 每张都断言了页面元素真的渲染出来（不是拍一张空白当成功）。

复跑：

```bash
venv\Scripts\python.exe app.py                  # 起服务（默认 5001，演示库 data/rmb01.db）
venv\Scripts\python.exe make_screenshots.py     # 拍 4 张，写进 docs/screenshots/
```

拍别的站点（比如临时库起在 5099）用环境变量：

```bash
set RMB01_SHOT_BASE=http://127.0.0.1:5099
venv\Scripts\python.exe make_screenshots.py
```

脚本**不造数据，只拍数据**：开拍前先探一遍——登得上 `demo-admin`、有知识库、
成员表里 3 种角色齐、登得上 `demo-platform`，缺什么当场报错。
数据来自 `demo_seed.py`（临时库）或仓库自带的演示库。

2026-10-21 这一轮按新 UI 重拍了 4 张（登录页改成左右分栏 + 演示账号卡片、
问答拆成列表页 / 分段预览 / 单库问答三个页面、企业后台加了 KPI 卡与角色下拉）。

## 2 · 知识库问答（核心页）

![知识库问答](screenshots/2-知识库问答.png)

> 1280x900。取景要保证「提问 + 结果 + 引用卡片」同屏 —— 800 高时引用卡片会掉到视口外。
> 脚本会量关键元素的 `getBoundingClientRect`，不在视口内就拒绝出图。

**这一张就是整个项目的卖点**：

| 区块 | 内容 |
|---|---|
| 顶部导航 | 当前是「企业管理员」，所以有「知识库 / 企业后台」，**没有「平台后台」** |
| 提问卡 | 「数据库连接超时怎么处理」，右侧标「取前 3 段」；下方是**「用模型生成答案」勾选框**（未勾）+ 一行提示「模型 Qwen/Qwen3.8-27B：勾选后由模型总结，消耗 1 次额度；不勾只返回检索原文，不计费」，再下面是快捷问题 |
| **结果卡** | 🔴 **规则兜底态**：标题「检索原文（未经模型总结）」+ 徽标「规则兜底 / 命中 2 段 / 不计费」，正文是带 `[doc:N]` 的原文，末尾「降级原因」 |
| 🔴 **引用材料** | 两张卡片，都精确到段：`#1 [doc:1] 运维手册 第 1 段 分 3.07`、`#2 [doc:2] 运维手册 第 2 段`，各带一句原文预览 |

> 默认不勾模型，所以拍下来是**兜底态**——没有模型总结，但检索、引用、计费口径都是真的：
> 正文就是命中的原文，`[doc:N]` 照样能点回右上的卡片，页面上直接写「不计费」。
> 勾上「用模型生成答案」后同一页显示模型写的答案，徽标变绿「正常 / 计 1 次额度」。

**这张图证明的链路**：
上传《运维手册》→ 分段 → 提问 → BM25 命中第 1、2 段 → 引用卡片指回去 → 降级不计费。

## 页面清单与权限

| 路由 | 谁能进 | 截图 |
|---|---|---|
| `/login` | 所有人 | ✅ |
| `/kbs` | 有租户的已登录账号 | ✅ |
| `/kbs/<id>` | 库属于本租户，且有 `view_history` | |
| `/kbs/<id>/ask` | 同上 + 有 `ask`（只读不行） | ✅ |
| `/compare` | 有租户 + `view_history` | |
| `/org` | **仅企业管理员** | ✅ |
| `/org/usage` | **仅企业管理员** | |
| `/platform` | **仅平台管理员** | ✅ |
| `/platform/tenants/<id>` | **仅平台管理员** | |
| `/me` | 所有已登录 | |

权限矩阵（`tests/test_pages.py` + `tests/test_maintenance_round.py` 锁着，不是嘴上说）：

| 角色 | `/kbs` | `/kbs/<id>/ask` | `/org` | `/platform` |
|---|---|---|---|---|
| 企业管理员 | 200 | 200 | 200 | **403** |
| 成员 | 200 | 200 | **403** | 403 |
| 只读 | 200 | **403** | **403** | 403 |
| 平台管理员 | **302 → /platform** | 404 页 | **403** | 200 |

> 平台管理员访问 `/kbs` 会被送去 `/platform`：他没有租户，
> 与其渲染一个接口全报错的空页，不如直接给能用的那一页。
